### Challenge
File upload - Double extensions

### Goal
Your goal is to hack this photo galery by uploading PHP code.  
Retrieve the validation password in the file .passwd at the root of the application.

### Walkthrough
- I uploaded a basic `test.png` file to understand the normal behavior of the web application.
- <img width="600"  alt="image" src="https://github.com/user-attachments/assets/8fc5e3fa-032f-4b87-9e9f-af7e2cc050b5" />
- Next, I uploaded a file named `test.php`, but it showed the message "Wrong extension".
- <img width="600"  alt="image" src="https://github.com/user-attachments/assets/96731eb5-016b-49f2-b61e-f6abd0eb0cfc" />
- I then renamed the file to `test.php.png`, and it was uploaded successfully.
- <img width="600"  alt="image" src="https://github.com/user-attachments/assets/ebba807a-95ce-40fe-b815-f95c83c02215" />
- From this behavior, I confirmed that the file extension was strictly validated, but the file content was not validated.
- This also suggested that the upload filter only checked the final extension, while the server still interpreted the file
  based on its PHP extension in the filename.
- I created a file named `test4.php.png` with the following content:
```
<?php
echo file_get_contents("/.password");
?>
```
- <img width="600"  alt="image" src="https://github.com/user-attachments/assets/0ae908bc-615d-426d-94af-3944dd5d46a9" />
- When I executed this PHP code, it showed an error message: **"Failed to open stream"**.
- I understood that although I had bypassed the file extension filter, the `.passwd` file was not located inside the
  current upload directory.
- I realized that the `.passwd` file was located in the application root directory.
- So, I used path traversal to move from the upload directory to the application root and access the `.passwd` file.
```
<?php
echo "Attempting to read .passwd:<br>";
include('../../../.passwd');
?>
```
- This successfully read the password file and revealed the validation password.
- <img width="600"  alt="image" src="https://github.com/user-attachments/assets/dfaa2230-e646-473b-8f1b-6aa4d3d057a2" />

### Key Learnings
- `include()` executes the specified file on the server.
- Double extension bypasses can work when the upload filter validates only the final extension.
- Some servers may still interpret files as PHP when a `.php` extension exists in the filename.
- Path traversal can be used to access files outside the current directory.
